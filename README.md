# AMD DESIGN — site vitrine

Site statique (HTML/CSS/JS, sans build) du cabinet AMD Design : Architecture • Bâtiment • Urbanisme • 3D.

- Aperçu local : `python3 -m http.server` puis http://localhost:8000
- Images : voir `img/README.md`
- Hébergement : GitHub Pages (Settings → Pages → branche `main`, dossier `/`). Pour le domaine, ajouter un fichier `CNAME` contenant `www.amddesign-archi3d.com` et configurer le DNS (CNAME `www` → `jordyadopo-boop.github.io`).
