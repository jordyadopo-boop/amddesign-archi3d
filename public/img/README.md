# Images à fournir

Les fichiers `.svg` actuels sont des **placeholders**. Remplacez-les par de vraies photos (JPG/WebP, ~1600 px de large, < 300 Ko) en gardant le même nom, puis changez l'extension dans `index.html` (ex. `projet-1.svg` → `projet-1.jpg`).

| Fichier | Contenu attendu |
|---|---|
| `hero-nuit.*` | Bâtiment moderne béton/verre de nuit (croix lumineuse) — fond du hero |
| `projet-1.*` … `projet-8.*` | Réalisations (villas, immeubles, rendus 3D, rénovation). Mettre à jour titre, lieu et catégorie (`data-cat`) dans `index.html` |
| `avant-croquis.*` | Croquis filaire / plan d'un projet (même cadrage que l'image après) |
| `apres-rendu.*` | Rendu 3D final du même projet (ex. vue aérienne des villas blanches avec palmiers) |
| `og-image.jpg` | Image de partage réseaux sociaux, 1200×630 (à créer) |
| `logo.svg`, `favicon.svg` | Logo AMD recréé en SVG — remplaçable par le fichier officiel |
